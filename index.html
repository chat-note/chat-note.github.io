帳號管理
所有帳號互通：第一個同步的帳號是主帳，筆記只存主帳的 Drive，其他帳號都能編輯，沒有誰的資料優先（逐則比最後修改時間）。帳號名單會隨筆記同步，在任何一個帳號新增或移除，其他帳號下次同步就會跟上。主帳滿了時，新圖片可改存到其他帳號。

兩個帳號都可以編輯；同一則筆記兩邊都改過時，留下較新的。「匯入備份」仍會覆蓋這台裝置的資料。

本機儲存空間

圖片與附件存在這台裝置的瀏覽器裡。超過門檻的檔案，同步時不會自動下載，點開時才從 Drive 下載。「釋放本機大檔」只會清掉已確認備份在雲端的檔案，雲端那份不會被刪。填 0 代表同步時不略過任何檔案，此時「釋放」會釋放全部已備份的檔案。

Google Drive 同步

圖片與附件放在你 Drive 裡的「oc-notes-shared」資料夾（尚未開啟上面的 Gist 同步時，筆記和聊天紀錄也放這裡；開啟後文字改存 Gist，Drive 只留圖片、附件和帳號名單）。要讓另一個帳號也能同步，先到「帳號管理」按「新增帳號」並登入它，主資料夾會自動共用給它（可編輯），再用那個帳號登入同步即可。同步會逐則比對最後修改時間，新的留下、不會整份覆蓋；刪除也會一起同步。上傳後會順便清掉沒在用的雲端圖片。授權約 1 小時有效，過期請再按一次。你也可以直接點右上角的 Chatnote 標誌來同步（聊天、筆記本、AI 摘要頁都能用）。

GitHub Gist 同步

聊天、筆記本、AI 摘要的文字（含 API 金鑰）會先在本機用權杖當金鑰加密，再存到你 GitHub 的一個私密 Gist。權杖不會過期，所以不用像 Drive 那樣每小時重新授權；Drive 只負責圖片與附件。

取得權杖：github.com → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)，只勾 gist，Expiration 選 No expiration。（fine-grained 權杖不支援 Gist，不能用。）第二台裝置登入 Google 後按右上角 Chatnote 標誌，會自動從 Drive 取得權杖，並找到同一個 Gist。權杖會以明文放在你的 Drive，請確保 Drive 帳號安全。

匯出 CSV（Anki）

圖片與對話會送到你目前選用的服務商處理；免費層的內容可能被用於改進產品，請不要上傳不想外流的資料。資料存在這台裝置的瀏覽器，請用 Google Drive 同步或定期匯出。
